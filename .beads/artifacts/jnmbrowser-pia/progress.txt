# Progress Log

Bead: jnmbrowser-pia

## Codebase Patterns

- BrowserRunner owns browser launch, process lifecycle, pre-launch rollback, fingerprint regeneration, and ephemeral directory handling.
- ephemeral_dirs.rs owns transactional runtime directory replacement, deletion retries, startup recovery, and effective-path resolution.
- Two-factor Backfill provides the strongest existing cleanup guard, ownership check, rollback, and stale-recovery pattern.
- Auto Registration already tracks worker ownership and has backend profile_id validation, but normal UI wiring and immutable runtime adoption are incomplete.
- All user-visible frontend strings must be translated in seven locale files; Tauri listeners must be installed before starting work.

## Specification Notes

- Selected architecture: Option C (Recommended), using immutable source profiles, runtime launch policy, runtime data/fingerprint overrides, and a full lifecycle lease.
- `/create` intentionally writes specification artifacts only. Application implementation belongs to `/ship jnmbrowser-pia` after planning and file reservation.
- Existing dirty worktree changes on feat/auto-reg-2fa-backfill are pre-existing and must remain untouched.
